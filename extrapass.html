Project

Extra Pass Analytics

Advanced basketball statistics analysis using a Four Factor framework.

Overview

ExtraPass explores team and player performance through pace, shooting efficiency, turnovers, and rebounding. This page is a project landing page for the portfolio.

  • Four-factor team analysis for all games (2000-2026)
  • Play-by-play timelines with win probabilities
  • Advanced stats league summary over custom horizons
  • Statistical trend charts
  • Contributions to performance over custom horizons
