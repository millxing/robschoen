## Editing content

The site is static HTML generated from one content file. Never edit the generated pages
(`index.html`, `projects.html`, `writing.html`, and the post pages): the next rebuild overwrites them.

Two ways to change content:

1. **Editor (recommended):** run `./run-editor.sh`, open `http://127.0.0.1:4173/post-studio.html`,
   edit, and click `Save + Rebuild`. See "Site Editor" below.
2. **By hand:** edit `content/site-content.mjs`, then regenerate every page with:

   ```sh
   node tools/post_generator.mjs
   ```

Then commit and push to `main`; GitHub Pages republishes https://entangledparticles.xyz/ in a few minutes.

Preview locally before pushing with `python3 -m http.server 8765` and open `http://127.0.0.1:8765/`.

### Per-entry fields worth knowing

- `importance` (1–100): sort order on the homepage and archives, highest first.
- `homeHref`: where the card links. A `./slug.html` link opens the post page; a full `https://` URL
  opens the external site in a new tab and the card shows "Visit domain ↗".
- `homeCardText`: the card summary (also used on the archive pages).
- `cardImage`: the card thumbnail, e.g. `./assets/thumbs/slug.jpg`. Use a 16:9 image about 960×540 px.
- `homeTag`: optional badge next to the category, e.g. `Updated`.
- `hiddenFromListings`: keeps the post page but removes it from the homepage, archives and previous/next links.
- `pageIntroText`: the opening text in the post's title card. If empty, a leading plain-text block is used.

### Media

- A GIF with a matching `.mp4` and `-poster.jpg` next to it (e.g. `clip.gif`, `clip.mp4`, `clip-poster.jpg`)
  is served as a lightweight looping video automatically. To convert a GIF:

  ```sh
  ffmpeg -i clip.gif -movflags +faststart -pix_fmt yuv420p -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" -c:v libx264 -crf 24 -an clip.mp4
  ffmpeg -i clip.gif -vframes 1 -q:v 3 clip-poster.jpg
  ```

- Standalone images in posts can be enlarged by clicking. Images with a link navigate instead.

## Styling

- Colors, fonts and spacing are tokens under `:root` in `styles.css`.
- Floating background squares are tuned in `renderBackgroundScripts()` in `tools/post_generator.mjs`
  (`density`, `shape`, `size`, `speed`).

## Site Editor

Projects and writing now use one simple local editor.

1. Run `./run-editor.sh`
2. Open `http://127.0.0.1:4173/post-studio.html`
3. Choose `Projects` or `Writing`
4. Edit plain text and click `Save + Rebuild`

If you prefer, the direct command still works: `node tools/post_studio_server.mjs`

Formatting in text fields:

- `[b]bold[/b]`
- `[i]italic[/i]`
- `[code]code[/code]`
- `[link https://example.com]link text[/link]`
- `[center]centered text[/center]`
- `[cta_image src="./assets/example.png" alt="Description" href="https://example.com"]PLAY THE GAME[/cta_image]`
- `[image src="./assets/example.png" alt="Description"]Caption[/image]`
- `[table] ... [/table]` for tables using `left | right` rows
- Within a `[text]` block with an image, put `[after_image]` before prose that should follow the image.
- `[image_grid] ... [/image_grid]` for responsive image grids using `description | ./assets/image.gif` rows
- `[embed src="./assets/demo.mp4" title="Gameplay video"][/embed]` for a muted, looping video with playback controls
- blank line = new paragraph
- `- item` = bullet point

The detail page editor is now one linear `Body document` field per item, so you can mix normal
text and tables in order without separate block editors.

Source of truth:

- `content/site-content.mjs`
- `tools/post_generator.mjs`
- `post-studio.html`

Generated from that source:

- `index.html`
- `projects.html`
- `writing.html`
- detail pages such as `tm.html`, `sol_lewitt.html`, and `warren.html`

## Importance index

Use an importance index from `1-100` to sort entries in descending order (higher = closer to top).
The current values live in `content/site-content.mjs` (the `importance` field on each entry).

## File map

- `index.html`, `projects.html`, `writing.html`, post pages: generated by `tools/post_generator.mjs`; do not edit by hand
- `content/site-content.mjs`: all site content (source of truth)
- `assets/thumbs/`: homepage card thumbnails
- `index_old.html`: archived homepage layout (not regenerated; uses `styles-legacy.css`)
- `styles.css`: design tokens, layout and component styles for every generated page
- `styles-legacy.css`: frozen copy of the pre-redesign styles for archived pages
- `site.js`: image enlargement, looping-video playback and homepage filters
- `background.js`: param-driven floating background engine
